# Dogma-TS

An AI port of Dogma Go to TypeScript

- dogma-go-reference
  This is a copy of the Dogma Go repos at the point in time of the AI conversion

- dogma-ts
  This is the full AI conversion based on referencing the dogma-go-reference
  repos and the partially hand ported dogma-ts-prototype

- dogma-ts-prototype
  This is the original partially hand ported version of dogma-ts of which the
  message patterns were referenced for the final AI conversion in dogma-ts
